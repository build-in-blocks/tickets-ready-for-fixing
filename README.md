# @build-in-blocks/tickets-ready-for-fixing
Issue reports found in this repository are those that have been sorted, cleaned up, well defined, and deemed "ready to be worked on" for Build in Blocks maintainers and contributors. This repository is connected to our project board. Find "ready for fixing" issue tickets to take on through the project board here: [Build in Blocks Project Board](https://github.com/orgs/build-in-blocks/projects/1/views/1?pane=info).

#

> [!NOTE]  
> If you notice any issues with any of our projects or products, do not submit issues to this repository. Instead, you should submit issues you find to the [@build-in-blocks/product-issue-reports](https://github.com/build-in-blocks/product-issue-reports) repository.
